EduSupport – Student Support and Ticket Management System

About the Project:
EduSupport is a web-based Student Support and Ticket Management System developed to simplify student support requests and ticket management.
The system provides three separate dashboards: Student, Staff, and Manager.

Features
1. Student Dashboard
- Create support tickets.
- View submitted tickets.
- Track ticket status.

2. Staff Dashboard
- View student support tickets.
- Assign tickets to staff members.
- Update ticket status.
- View ticket activity.

3. Manager Dashboard
- View all student support tickets.
- Monitor ticket statistics.
- Filter tickets by status and priority.
- View ticket activity history.

Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Select a role and log in.
5. Explore the respective dashboard.

Data Storage
The application uses browser Local Storage to save and manage ticket information.

Project Objective
To provide a simple platform for students to raise support requests and help staff and managers track and manage tickets efficiently.
